    n1, n2, n3, n4, n5 : inteiro

// Observações importantes: "Como os procedimentos não retornam valores, não podem ser usados em expressões, como as funções."
// "Quando utilizar uma função e quando utilizar um procedimento? Deve-se optar por uma função quando se tem interesse num valor resultante 
// do processamento. Por exemplo, dado um número, verificar se ele é par. Neste caso, o mais adequado seria o emprego de uma função cujo retorno
// é do tipo lógico, pois se deseja uma resposta entre “sim” (V) e “não” (F). Mas, por outro lado, se o sub-algoritmo não precisa produzir um valor
// como resultado, o mais adequado é o uso de procedimentos. Um caso seria, por exemplo, mostrar um texto na tela."
